Why two checks?

A trend is “significant” when it would be very unlikely to appear by chance if nothing were really changing. The usual quick test can get this wrong in two ways.

1 · Seasons hide trends

Summer and winter swing the monthly values far more than any slow change. A line fitted to the raw months sees mostly that swing, so it can miss a real trend. The careful check first subtracts the usual value for each calendar month.

2 · Months have memory

A warm month is often followed by another warm month. Neighbouring months repeat part of the same information, so 540 months are worth fewer than 540 independent measurements. Ignoring this makes chance wiggles look like trends.

3 · Two tests must agree

The careful check runs a line fit that corrects for this memory, and a rank-based test (Mann-Kendall, modified for memory) that does not assume bell-shaped data. It calls a trend strong only when both agree.

For a single season (one value per year) there is no seasonal cycle to remove, so step 1 is not needed. Steps 2 and 3 still apply.

About the data

All series are monthly values from NASA sources. Each answer panel names its dataset.

When you check your own place, this page asks the NASA POWER service for that point's monthly record (MERRA-2 reanalysis, 1981 to 2025) and runs the tests in your browser. The saved records below were analysed in advance with the same methods.

    Reanalysis data such as MERRA-2 blend satellite and other observations with a weather model. Changes in the observing system over the decades can add artificial trends, especially for rainfall. Treat single-point results as a starting point for investigation, not as a final scientific finding.
